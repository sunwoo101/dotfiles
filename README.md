# dotfiles

Hyprland + Quickshell on Arch. Catppuccin Mocha, live-reload theming.

Inspired by Caelestia dotfiles.

https://github.com/user-attachments/assets/d1c3d8b9-23e3-467b-9152-03d4997183e6

## Install

```sh
git clone https://github.com/<you>/dotfiles ~/dotfiles
cd ~/dotfiles
./install_x86_64.sh   # or ./install_arm.sh
```
